# 附加组件管理器
允许切换附加组件的启用/禁用状态，并提供对其设置的访问（如果支持）。
双击标题栏可将窗口固定在界面最上层。

![附加组件管理器](https://i.imgur.com/C4DWrRA.png)

**注意：**

由于附加组件 API 的一个 bug，任何在 Esc 菜单中创建按钮的附加组件
每次重新加载或切换启用时都会新增一个按钮，而不会移除之前的按钮。

**警告：重新加载可能导致客户端崩溃**

附加组件的重新加载通常是安全的，但在某些情况下**可能会导致崩溃**：
- 无限循环
- UI 内存泄漏或纹理加载问题
- 与其他附加组件或现有 UI 对象的冲突

## 开发者
每个附加组件旁边的设置按钮会为该附加组件触发 `UI_ADDON` 事件。
