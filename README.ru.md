# Менеджер дополнений
Позволяет включать/выключать дополнения и предоставляет доступ к их настройкам (если поддерживается).
Дважды щёлкните по заголовку окна, чтобы закрепить его поверх интерфейса.

![Менеджер дополнений](https://i.imgur.com/C4DWrRA.png)

## Разработчикам
Кнопка настроек рядом с каждым дополнением вызывает событие `UI_ADDON` для этого дополнения.
