# Менеджер дополнений
Позволяет включать/выключать дополнения и предоставляет доступ к их настройкам (если поддерживается).
Дважды щёлкните по заголовку окна, чтобы закрепить его поверх интерфейса.

![Менеджер дополнений](https://i.imgur.com/C4DWrRA.png)

**ПРЕДУПРЕЖДЕНИЕ: Перезагрузка может привести к краху клиента**

**Примечание :**

Из-за бага в API аддонов любой аддон, создающий кнопку в меню Escape, будет
добавлять новую кнопку при каждой перезагрузке или включении, не удаляя предыдущую.

Перезагрузка аддонов в целом безопасна, но **может вызвать краши** в определённых ситуациях:
- Бесконечные циклы
- Утечки памяти интерфейса или проблемы с загрузкой текстур
- Конфликты с другими аддонами или существующими объектами интерфейса

## Разработчикам
Кнопка настроек рядом с каждым дополнением вызывает событие `UI_ADDON` для этого дополнения.
